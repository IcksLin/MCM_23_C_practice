# 问题 1 编程实现与运行说明

本目录实现 2024 年数学建模国赛 C 题问题 1 的混合整数线性规划（MILP）求解、约束审计、结果表回填、敏感性分析和绘图流程。

## 一键运行

Windows 下双击 `一键运行问题1.bat`，或在本目录终端执行：

```bat
一键运行问题1.bat
```

脚本先运行 P1 最小纵向门禁；门禁通过后，求解两种滞销情形并生成敏感性结果、图表和报告。正式流程会在终端显示 0%—100% 的文本进度条。使用 PATH 中的 `python`（激活 Anaconda/Miniconda 环境即可）。

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

## 模型口径

- 决策变量：地块—作物—年份—季次种植面积，以及是否启用种植组合的 0-1 变量。
- 情形 1：产量超过预计销售量的部分不产生销售收入，按浪费处理。
- 情形 2：超出预计销售量的部分按正常售价的 50% 销售。
- 预计销售量来自题目附件给出的基准数据推算，不虚构“2023 年实际销售量”字段。
- 核心目标是在耕地适宜性、面积、轮作、豆类覆盖、水浇地种植模式和最小种植面积等约束下最大化 2024—2030 年总利润。
- 第二阶段采用字典序优化：固定第一阶段最优利润容差后，减少启用的地块—作物组合数，使方案更集中、更易实施。

## 代码职责

- `algorithms/io_data.py`：读取题目附件并校验输入。
- `algorithms/preprocess.py`：清洗、映射地块和作物参数。
- `algorithms/model.py`：构造 MILP 变量、目标函数和约束矩阵。
- `algorithms/solve.py`：主目标与字典序阶段求解、解提取。
- `algorithms/validate.py`：独立复算面积、轮作、产量、销售量和利润等约束。
- `algorithms/export_excel.py`：按模板回填结果并执行回读核验。
- `algorithms/plots.py`：生成可编辑文字的 SVG/PNG 图表。
- `scripts/run_q1.py`：正式流水线与终端进度条。
- `scripts/p1_test.py`：使用真实数据执行最小纵向门禁，临时结果不覆盖正式工作簿。
- `scripts/pipeline_test.py`：在临时目录测试两种情形的完整流水线。

## 手动运行

```powershell
python scripts/run_q1.py --scenario both --eta 0.5 --delta 0.001 --demand-scale 1.0 --mip-gap 0.001 --time-limit 600 --seed 2024 --sensitivity --figures --reports
```

主要参数：

- `--scenario 1|2|both`：选择滞销处理情形。
- `--eta`：最小种植面积比例（地块面积的最小占比）。
- `--delta`：利润容忍度δ，0.001=允许0.1%利润损失换取更少种植激活。
- `--demand-scale`：预计销售量整体缩放系数。
- `--mip-gap`、`--time-limit`：求解终止条件。
- `--sensitivity`、`--figures`、`--reports`：生成扩展产物。

## 结果与判定

正式结果位于 `outputs/q1/`。程序只在约束审计和 Excel 回读均通过后原子替换正式工作簿；未认证的敏感性解不会伪装成最优值。求解器在时限内找到可行解但最优间隙未达阈值时，会保留 incumbent 供诊断，同时以非零退出码提示尚未达到交付门槛。

P1 仅证明读取—建模—求解—审计—Excel 回读链路可用，不等于独立 P2 终检。提交前仍应执行 P2，对最终参数、正式结果表、图表和报告进行独立复核。
