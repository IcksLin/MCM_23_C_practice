## 2. 模型概要

- 决策变量：$x_{jits}$（面积）、$y_{jits}$（激活）、$r_{jt}$（水浇地模式）、$Q_{its}$（产量）、$u_{its}$（正常销量）。
- 目标：情形1 $\max Z_1=\sum p u-\sum c x$（超额浪费）；情形2 $\max Z_2=\sum[p u+0.5p(Q-u)]-\sum c x$（超额半价）。
