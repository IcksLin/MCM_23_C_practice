# 三问实验评价标准

## 1. 固定对照文件

三问当前基准统一记录在 `doc/三问实验基准与对照.csv`。后续调参不得直接覆盖基准行，应以新的 `benchmark_id` 追加实验结果。

## 2. 统一优先级

1. **硬约束门禁**：`feasible=true` 且 `max_violation<=1e-4`。不通过时，利润再高也不能进入对比。
2. **口径一致**：只能在同一问题、同一情形、同一目标和同一情景流上比较。
3. **样本外效果**：优先比较配对 `oos_mean_profit`、`oos_cvar`和胜率，不仅比较训练目标。
4. **最优性证据**：使用正向 `objective_bound` 和 `corrected_gap`。
5. **稳定性**：比较多 seed、多 K 和参数敏感性；仅单次运行不能声称稳健。

## 3. gap 统一口径

最大化目标：

\[
LB=-f_{inc},\qquad UB=-f_{dual},\qquad
gap=\frac{\max(0,UB-LB)}{\max(|LB|,10^{-9})}.
\]

优化判定：

- 新解硬约束不通过：直接淘汰。
- 期望利润提高但 CVaR 明显降低：不得自动判为更优，须按风险偏好选择。
- 利润/CVaR 提高且 gap 不增大：判为明确改进。
- gap 下降但 incumbent 明显变差：只表示证明更强，不表示方案更优。

## 4. Q3 特殊区分

- `q3_integer_discovery`：用于比较全整数搜索的 incumbent 和全局界。
- `q3_fixed_refine`：用于比较固定种植结构后的面积/风险精炼。
- 两者 gap 不能混用：条件 gap 为 0 不等于全局 gap 为 0。
