## 已确认规则

### 规则 DC-01：孕周格式统一

设原始孕周为 `w+d`，转换后的十进制孕周为

\[
W=w+\frac{d}{7}.
\]

示例：

| 原始孕周 | 十进制孕周 |
|---|---:|
| `12w+0` | 12.0000 |
| `12w+3` | 12.4286 |
| `15w+6` | 15.8571 |

执行要求：无法匹配 `w+d` 形式、缺少孕周或天数超出合理范围时，不进行猜测性转换，应记录并进入异常检查。

### 规则 DC-02：重复检测分层处理

| 情形 | 处理方式 |
|---|---|
| 问题1的不同孕周重复检测 | 全部保留，使用孕妇随机截距描述同一孕妇记录间的相关性。 |
| 问题2、3的同孕妇同孕周重复检测 | Y染色体浓度取中位数，避免单次测量波动和重复计权。 |
| 问题2、3的同孕妇不同孕周检测 | 按十进制孕周排序，用于判断未达标—达标的时间区间。 |
| 训练、验证和测试划分 | 按孕妇划分，同一孕妇的记录不得跨集合。 |
| Bootstrap | 按孕妇抽样，不把同一孕妇的多条记录独立抽样。 |

处理后的数据单位：问题1仍为1082条纵向记录、267名孕妇；问题2、3为267条患者级记录。

### 规则 DC-03：首次达到4%的删失区间

在完成同孕妇同孕周中位数聚合后，按十进制孕周从早到晚排列，以 `Y染色体浓度≥0.04` 为达标标准。

| 删失类型 | 观测情况 | 区间构造 | 当前人数 |
|---|---|---|---:|
| 左删失 | 第一次检测已经达到4% | `T∈[0,U]`，其中 `U` 为第一次检测孕周 | 217 |
| 区间删失 | 前一次未达到4%，后一次达到4% | `T∈[L,U]`，其中 `L` 为最后一次未达标孕周，`U` 为第一次达标孕周 | 43 |
| 右删失 | 所有检测均未达到4% | `T∈[L,+∞)`，其中 `L` 为最后一次检测孕周 | 7 |

执行要求：三类样本全部保留；不使用区间中点代替首次达标时间，不把第一次达标检测孕周视为精确事件时间。

### 规则 DC-04：缺失值分类处理

| 缺失类型 | 当前处理 |
|---|---|
| 男胎末次月经缺失12条 | 问题1—3直接使用检测孕周，不使用末次月经；缺失值保留但不进入模型。 |
| 男胎非整倍体字段空白956条 | 该字段不作为问题1—3的输入或结局，不进行填补。 |
| 问题1—3关键建模字段缺失 | 不做均值、众数等隐式填补；缺失、非有限或无法转换时停止运行并检查数据。 |
| 女胎两列全空无名列 | 直接删除，不进入特征集合。 |
| 女胎BMI缺失1条 | 在每一个外层/内层训练折内用该训练折BMI中位数填补；同时增加“BMI缺失”指示变量。验证折和测试折只使用对应训练折中位数。 |
| 女胎非整倍体字段空白 | 按附件输出语义解释为未列出T13、T18、T21异常，相应标签记为0；该标签不等同于真实临床诊断终点。 |

执行要求：所有填补参数只能从当前训练折计算，禁止使用全数据或测试折统计量；除上述已定义情形外，不自动填补未知字段。

## 三、第一问解答

### 1. 数据特征分析

| 项目 | 数据特征 | 对建模的影响 |
|---|---|---|
| 样本结构 | 男胎1082条检测记录对应267名孕妇，同一孕妇存在重复检测 | 记录之间并非相互独立，需要显式处理孕妇内相关性 |
| 检测孕周 | 范围11—29周，均值约16.846周 | 可以分析Y浓度随孕周的纵向变化，并需要考虑非线性 |
| BMI | 范围20.703—46.875，均值约32.289 | 样本整体BMI偏高，需检验BMI主效应及其与孕周的交互 |
| Y染色体浓度 | 均值0.07719，中位数0.07507，为0—1之间的比例变量 | 不宜直接无限外推，需要进行logit变换 |
| 其他变量 | 包括年龄、身高、IVF、读段数、比对比例和GC含量 | 可作为扩展变量检验是否提供额外统计解释量 |

第一问的核心任务是解释变量关系与显著性，而不是寻找最佳检测时点或构建分类器。

### 2. 数据预处理方案

| 处理步骤 | 具体做法 | 目的 |
|---|---|---|
| 数据身份核验 | 检查附件SHA-256、1082条记录、267名孕妇及首末序号 | 防止输入版本发生变化 |
| 孕周转换 | 将`w+d`转换为`w+d/7`十进制周 | 支持数值计算、排序和曲线建模 |
| 重复检测 | 问题1保留全部1082条记录，以孕妇代码标识重复测量 | 保留Y浓度随孕周变化的纵向信息 |
| Y浓度变换 | 将Y浓度截断保护到`[10^-6,1-10^-6]`后进行logit变换 | 适应比例变量边界并避免0、1导致无穷值 |
| 连续变量标准化 | 孕周、BMI、年龄、身高、比对比例和GC含量减均值后除以标准差 | 改善模型数值稳定性，并使系数可按一个标准差解释 |
| 读段数处理 | 唯一比对读段数先取自然对数，再标准化 | 缓解量级过大和右偏问题 |
| IVF编码 | 自然受孕记为0，其他IVF方式记为1 | 将类别变量转换为模型可用的二元变量 |
| 缺失检查 | Y浓度等关键字段缺失时停止运行，不做隐式填补 | 避免用未经确认的填补假设影响显著性 |

### 3. 模型选取及缘由

主模型选用以孕妇为随机截距的线性混合效应模型，原因如下：

1. 同一孕妇的多次检测存在相关性，普通线性回归的独立性假设不成立。
2. 随机截距可以描述不同孕妇Y浓度基础水平的个体差异。
3. 固定效应系数、置信区间和显著性检验便于直接回答题目要求的关系方向。
4. 加入孕周二次项可以描述非线性变化；加入孕周×BMI交互项可以检验BMI是否改变孕周效应。
5. 第一问属于统计关系解释，不以搜索树或黑箱预测模型作为主模型。

### 4. 模型及其参数介绍

基础模型为

\[
\operatorname{logit}(Y_{ij})=\beta_0+\beta_1W_{ij}+\beta_2W_{ij}^{2}
+\beta_3B_{ij}+\beta_4W_{ij}B_{ij}+u_i+\varepsilon_{ij},
\]

其中：

| 参数 | 含义 |
|---|---|
| `β0` | 所有标准化连续变量处于均值附近时的总体截距 |
| `β1` | 平均孕周附近，孕周增加一个标准差对应的Y浓度logit变化 |
| `β2` | 孕周关系的曲率，用于判断是否偏离直线关系 |
| `β3` | 相同孕周附近，BMI增加一个标准差对应的Y浓度logit变化 |
| `β4` | 孕周与BMI交互效应，检验BMI是否改变孕周增长斜率 |
| `u_i` | 第`i`名孕妇的随机截距，`u_i~N(0,σ_u²)` |
| `ε_ij` | 第`i`名孕妇第`j`次检测的记录级误差，`ε_ij~N(0,σ²)` |

扩展模型在基础模型上增加年龄、身高、IVF、对数唯一比对读段数、参考基因组比对比例和GC含量。基础模型和扩展模型均采用最大似然估计，优化方法为L-BFGS，最多迭代1000次。

### 5. 模型训练

第一问中的`β`、随机截距方差和残差方差不是人工设定或网格搜索得到的，而是由全部1082条纵向记录通过最大似然估计共同求得。

1. 先按照给定参数计算每条记录的条件均值，并结合孕妇随机截距构造整组纵向观测的联合似然。
2. 对随机效应积分后得到边际对数似然；代码使用L-BFGS迭代寻找使对数似然最大的参数组合。
3. 基础模型和扩展模型均使用`REML=False`的最大似然估计，确保两模型的似然值可以用于似然比检验。
4. 迭代最多1000次；若模型未收敛，则停止接受当前结果，不能直接引用系数。
5. 参数标准误由拟合点附近的曲率信息估计；Wald统计量、p值及95%置信区间均由“系数÷标准误”及其近似分布得到。

这里不存在“训练集上调参、测试集上评分”的常规机器学习流程，因为第一问主要进行统计关系估计。若未来增加预测性验证，应按孕妇分组另做交叉验证，不能改变当前显著性检验口径。

### 6. 模型评分方式

| 评价方法 | 作用 | 判定方式 |
|---|---|---|
| Wald检验 | 判断单个固定效应系数是否显著偏离0 | 结合系数、标准误、p值和95%置信区间判断 |
| AIC | 比较模型拟合能力与复杂度的平衡 | AIC越低通常越优 |
| 似然比检验 | 检验扩展变量作为一个整体是否增加解释量 | 比较基础模型与扩展模型对数似然，报告LR、自由度和p值 |
| 收敛检查 | 确认参数优化是否成功 | 任一模型未收敛则不接受结果 |
| 随机效应与残差 | 判断孕妇间差异及记录级误差规模 | 比较随机截距标准差和残差标准差 |

第一问以参数估计和统计推断为目标，因此当前不使用训练集准确率作为评分，也不把预测交叉验证作为显著性结论的主要依据。

### 7. 数值结果分析

| 变量/检验 | 结果 | 解释 |
|---|---:|---|
| 孕周一次项 | `β=0.1668，p=3.32×10^-48` | 孕周与Y浓度显著正相关 |
| 孕周二次项 | `β=0.0428，p=5.80×10^-6` | 孕周关系存在显著曲率，不能完全视为恒定斜率 |
| BMI主效应 | `β=-0.0719，p=0.00250` | 相近孕周下，BMI越高，Y浓度整体越低 |
| 孕周×BMI | `β=0.00843，p=0.336` | 交互不显著，不能声称不同BMI人群的增长速度显著不同 |
| 基础模型AIC | `836.330` | 基础模型比较基准 |
| 扩展模型AIC | `817.693` | 加入辅助变量后AIC降低18.637 |
| 似然比检验 | `LR=30.637，df=6，p=2.97×10^-5` | 年龄、身高、IVF及测序变量整体增加统计解释量 |
| 孕妇随机截距标准差 | `0.434` | 孕妇之间的基础Y浓度差异明显 |
| 记录级残差标准差 | `0.261` | 同一孕妇内部仍存在检测波动和未解释误差 |

### 8. 结论解释与边界

第一问可以得出：Y染色体浓度随孕周总体升高，并存在一定非线性；BMI与Y浓度显著负相关。孕周与BMI交互项不显著，因此当前证据只支持“高BMI孕妇的Y浓度整体偏低”，不支持“不同BMI人群具有显著不同的增长速度”。扩展变量整体改善模型解释量，但不能把单项统计系数直接解释为因果作用。

该结论来自当前267名孕妇的内部纵向数据。样本来源单一且BMI分布偏高，因此不能直接外推到所有地区或临床人群。第一问的结果为问题2、3按BMI进行时点分流提供方向依据，但不能单独决定最终BMI切点和推荐孕周。

### 9. 补充

1. 若混合模型不收敛、随机效应退化或残差出现非有限值，应停止使用该结果，并考虑患者聚类稳健GEE作为同一解释目标下的备选实现。
2. 回退模型与混合模型的参数含义不同，必须在报告中明确区分，不能混合引用系数。
3. 如需评价第一问模型的预测外推能力，可另做按孕妇分组的交叉验证；该结果只能作为补充，不能替代Wald检验和似然比检验。
4. 所有系数均作用于标准化变量和Y浓度logit尺度，不能直接解释为Y浓度增加或减少相同数值的百分点。

## 四、第二问解答

### 1. 数据特征分析

本部分只描述数据现象如何阻碍“确定BMI分组及最佳NIPT时点”这一目标。

| 数据现象 | 对问题2的阻碍 |
|---|---|
| 1082条检测记录对应267名孕妇 | 检测记录不独立，直接按记录训练或划分会重复计权并产生患者泄漏 |
| 同一孕妇仅在若干离散孕周接受检测 | 无法观察首次达到4%的精确时点，只能形成左删失、区间删失或右删失 |
| 左删失217人、区间删失43人、右删失7人 | 普通回归无法正确使用三类不完整时间信息 |
| BMI范围20.703—46.875且分布不均衡 | 高BMI尾部样本较少，切点可能受少量样本扰动，不能机械追求等人数分组 |
| 达标概率通常随孕周增加 | 越晚检测越容易达到4%，但更晚发现潜在问题；“准确”与“尽早”存在冲突 |
| 题目把孕期风险分为≤12周、13—27周、≥28周三级 | 18周和22周在题面中同属中期；是否认为18周额外优于22周取决于风险解释 |
| 同孕妇同孕周重复测量存在波动 | 4%附近的状态可能因测量误差改变，需要检查推荐方案是否对扰动敏感 |

### 2. 问题分析

第二问需要依次解决四类问题：

| 大类问题 | 需要回答的具体内容 |
|---|---|
| 首次达标时间预测 | 如何利用三类删失信息估计孕妇在不同孕周前达到4%的概率 |
| BMI分组 | 分几组、切点设在哪里、如何避免局部贪心和极小样本组 |
| 分组稳定孕周 | 每个BMI组在哪个最早整数周能够稳定满足达标可靠性要求 |
| 题目风险解读 | “越早越好”与“通过率越高越好”如何同时进入判优；题面三级风险和连续等待风险如何区分 |

这里“推荐周期越早越好”是因为检测推迟可能延后后续确认与处理；但时间早不能凌驾于检测可靠性之上。正确的判优逻辑是：先满足可靠性和稳定性，再在安全候选中选择更早、结构更简单的方案。

### 3. 指标定义

设第`i`名孕妇推荐孕周为`t_i`，模型预测其在该周前达到4%的概率为`F_i(t_i)`。

| 指标 | 定义或门槛 | 含义 |
|---|---|---|
| 总体预测达标概率 | `mean[F_i(t_i)]` | 推荐时点前达到4%的平均预测概率 |
| 准确性风险 | `R_a=1-mean[F_i(t_i)]` | 推荐时点仍未达到4%的平均风险 |
| 平均推荐孕周 | `mean(t_i)` | 整体检测时间成本，越小表示越早 |
| 题面分段时间风险 | 按≤12周、13—27周、≥28周分级 | 严格按照题目风险区间比较等待损失 |
| 连续时间风险 | `R_t=mean[clip((t_i-13)/14,0,1)]` | 敏感性分析中假设13—27周内部等待损失连续增加 |
| 不稳定风险 | `R_s=1-重复折安全率` | 方案对重新划分数据的敏感程度 |
| 综合风险 | `R=w_aR_a+w_tR_t+w_sR_s`，权重非负且和为1 | 比较不同准确性、等待和稳定性偏好下的方案 |
| 组内平均达标安全线 | 至少0.89 | 固定政策部署审计的组内可靠性要求 |
| Bootstrap安全率 | 至少0.95 | 患者重采样后仍满足安全线的比例 |
| 重复折安全率 | 至少0.90 | 重复划分中安全折所占比例 |
| 重复4/4比例 | 至少0.70 | 100次重复四折中四折全部安全的比例 |

所有门槛在测试审计前固定，不能看到测试结果后临时降低。

### 4. 模型与算法组件及选取缘由

| 模型/算法 | 是什么 | 选取缘由 | 解决的问题 |
|---|---|---|---|
| 区间删失XGBoost-AFT | 将首次达到4%视为生存时间，用提升树学习特征与达标时间分布的非线性关系 | 能直接接收左删失、区间删失和右删失上下界，并表示BMI等变量的非线性和交互 | 首次达标时间不精确、普通回归无法使用删失样本的问题 |
| 患者级嵌套交叉验证 | 外层测试泛化、内层调参和早停，全部按孕妇划分 | 防止同一孕妇跨集合和测试折参与调参 | 患者泄漏、过拟合和不同方案比较不公平的问题 |
| 全局Optimal Binning | 按BMI排序，只在相邻不同BMI之间建立连续分段，并比较完整候选分组 | 相比单棵决策树的局部贪心切分，更适合寻找整体最优、可解释的连续BMI区间 | BMI分几组、切点在哪里及局部最优问题 |
| 组内最早安全周搜索 | 对每个候选组逐周计算预测达标概率并寻找满足安全要求的最早周 | 把连续概率预测转换为可执行的整数孕周建议 | 每组何时检测的问题 |
| Pareto/固定方案比较 | 同时比较达标概率、平均孕周、稳定性和复杂度 | 避免只追求最早或只追求最高通过率 | 多目标判优问题 |
| 患者Bootstrap、重复折与误差扰动 | 重采样患者、重复划分并扰动4%附近Y浓度 | 检查切点和时点是否由偶然样本或检测误差决定 | 稳定性与测量误差问题 |

XGBoost-AFT只负责产生`F_i(t)=P(T_i≤t|x_i)`；Optimal Binning负责BMI分组；安全周搜索负责推荐孕周。三者不能混写成一个单独算法。

### 5. 整体路线/算法结构

```text
1082条男胎检测记录
        ↓ 同孕妇同孕周Y浓度取中位数、按孕周排序
267条患者级删失记录
        ↓ 外4折、内3折患者级嵌套验证
区间删失XGBoost-AFT
        ↓ 得到不同孕妇、不同孕周的OOF达标概率
BMI稳定排序＋合法相邻切点
        ↓ 全局Optimal Binning比较连续分组
候选BMI组
        ↓ 逐组搜索满足可靠性的最早整数周
候选分组—时点政策
        ↓ 固定比较15/18、16/18、18/22
题面风险、连续风险、Bootstrap、重复折和误差审计
        ↓
题面主推荐18/22＋连续风险敏感性方案16/18
```

### 6. 训练方案

第二问包含三次相互衔接但目标不同的训练/优化：第一次训练达标时间分布，第二次训练BMI分组政策，第三次训练各组推荐时间。后两次本质上是基于冻结预测结果的决策参数优化，不再重新拟合Y浓度预测模型。

#### 6.1 第一次训练：XGBoost-AFT删失建模

**训练目标**：不猜测精确达标时间，直接利用左删失、区间删失和右删失上下界，学习每名孕妇首次达到4%的条件时间分布。

输入患者级数据样貌：

| 字段 | 含义 | 示例 |
|---|---|---|
| 孕妇代码 | 患者唯一标识 | `A001` |
| BMI等基线特征 | 检测前可以获得的特征 | BMI=28.516 |
| `lower` | 首次达标时间下界 | 15.857周 |
| `upper` | 首次达标时间上界 | 20.143周或`+∞` |
| `censoring` | `left`、`interval`或`right` | `interval` |
| `outer_fold` | 固定患者级外层折号 | 0—3 |

训练过程：

1. 由1082条记录构造267条患者级删失记录，按删失类型分层。
2. 外层4折中，每次约200名孕妇训练、66—67名孕妇测试；外层训练集内部固定3折用于超参数选择和早停。
3. 对左删失、区间删失和右删失样本分别最大化`F(U|x)`、`F(U|x)-F(L|x)`和`1-F(L|x)`，等价地最小化其负对数似然。
4. AFT误差分布、尺度及树模型参数只使用当前外层训练数据确定；当前四个外层折均选择极值分布，尺度约为0.733、0.781、0.778和0.578。
5. 每个外层模型只预测该折未见过的孕妇，最后拼接成完整OOF概率表。

XGBoost-AFT并没有把删失样本“补成一个确定孕周”。它把每个删失区间转换为一条随孕周单调上升的概率曲线。

第一次训练后的数据样貌：

| 数据规模/字段 | 结果 |
|---|---|
| 行数 | 267行，每名孕妇一行 |
| 身份与标签字段 | 孕妇代码、BMI、`lower`、`upper`、删失类型、外层折号 |
| 概率时间网格 | 10.000—25.000周，每隔1/7周计算一次 |
| 概率字段数 | 106列，记为`p_10.000`至`p_25.000` |
| 单元格含义 | `p_t=P(T≤t|x)`，表示在`t`周前达到4%的OOF预测概率 |

例如A001的删失区间为`[15.857,20.143]`，其OOF达标概率从10周的0.6936上升到16周的0.9305、18周的0.9620和22周的0.9902。该概率表是后两次训练共同使用的冻结输入。

#### 6.2 第二次训练：全局Optimal Binning确定BMI组数与切点

**训练目标**：在BMI连续、有序且每组样本量可靠的约束下，确定分几组以及切点在哪里，使各组存在足够早且安全的推荐孕周。

最终采用全局有序分组搜索：

1. 将267名孕妇按BMI稳定排序，只允许在相邻不同BMI值之间切分。
2. 每个开发折搜索`1..floor(n开发/30)`个连续组；约200名开发患者时覆盖1—6组，全样本理论上最多8组。
3. 对每个候选区间读取AFT的OOF周概率，寻找单侧90%置信下限达到0.95的最早整数孕周。
4. 在满足组规模和可靠性约束的完整分组中，通过动态规划最小化患者加权平均推荐孕周。
5. 在最优开发平均孕周0.25周以内优先选择组数更少的结构，再到完全留出的外层测试患者评价。

四个外折中一组和两组各被选择2次，3组及以上均未胜出；平均测试孕周18.949周、平均测试达标概率0.9556，均值安全4/4折、保守LCB安全3/4折。因此数据支持简单分组结构，最终为部署可解释性采用两组政策。

第二次训练的最终分组：

| 最终BMI范围 | 人数 | 占比 |
|---|---:|---:|
| `BMI<34.357` | 215 | 80.5% |
| `BMI≥34.357` | 52 | 19.5% |

固定切点网格审计表明，在每组至少30人并完成4个外折的条件下，29.75—34.50为均值与LCB均4/4安全的平台；算法切点34.357位于该平台内。

#### 6.3 第三次训练：最优推荐时间与安全裕量校准

**训练目标**：在第二次训练固定的两组结构下，为低BMI组和高BMI组选择可执行的推荐孕周，处理“越早越好”和“达标概率越高越好”的冲突。

使用100次重复四折和患者Bootstrap比较最终可执行方案：

| 最终比较方案 | Bootstrap安全率 | 重复折安全率 | 重复4/4比例 | 定位 |
|---|---:|---:|---:|---|
| 15/18 | 0.9812 | 0.83 | 0.41 | 重复划分不稳定，淘汰 |
| 16/18 | 0.9976 | 0.94 | 0.77 | 连续等待风险下的效率折中方案 |
| 18/22 | 1.0000 | 1.00 | 1.00 | 题面三级风险下的主推荐 |

第三次训练最终没有只输出一个“数学最早周”，而是输出两层政策：题面把18周和22周都视为中期，因此主推荐选择准确性和稳定性更高的18/22；如果额外假定13—27周内部等待损失连续增加，则保留16/18作为风险权重敏感性方案。

### 7. 验证方案

| 验证层 | 做法 | 作用 |
|---|---|---|
| 外层4折 | 按删失类型分层，每名孕妇仅出现于一个测试折 | 生成未参与该折训练的患者级OOF概率 |
| 内层3折 | 仅在外层训练集内调参和早停 | 隔离模型选择与外层评价 |
| 固定政策回放 | 在同一批冻结预测上比较15/18、16/18和18/22 | 保证不同政策使用相同预测基础 |
| 患者Bootstrap | 以孕妇为单位重采样，不独立抽取检测记录 | 估计组内可靠性和方案排序的抽样波动 |
| 100次重复四折 | 改变患者折分后重新检查各折安全性 | 评价方案对数据划分的稳定性 |
| 测量误差敏感性 | 根据同孕妇同孕周重复检测估计误差并扰动Y浓度 | 检查4%附近状态改变是否推翻方案排序 |

上述属于内部验证，不是来自新医院或新时间段的外部测试。最终切点和固定政策经过当前数据开发，不能把内部回放结果表述为完全独立的无偏临床成绩。

## 五、第三问解答

### 1. 数据特征分析

沿用前述267名孕妇的患者级删失数据、重复检测聚合、孕周转换、患者级划分和删失区间构造规则，不再重复展开。

新增使用年龄、身高、体重、IVF、孕次和产次等检测前因素。当前主要障碍为：变量增加后过拟合风险上升；BMI、身高和体重之间存在相关性；高BMI尾部样本较少；平均达标概率可能掩盖组内高风险个体；多因素概率最终仍需压缩成可执行的BMI分组；测量误差可能改变4%附近样本的达标状态。

### 2. 问题分析

| 大类问题 | 具体任务 |
|---|---|
| 多因素达标建模 | 综合年龄、身高、体重、BMI、IVF、孕次和产次估计不同孕周前达到4%的概率 |
| 分组结构优化 | 根据多因素概率确定合理的BMI组数及连续切点 |
| 组内安全周期 | 为每个BMI组寻找满足可靠性要求的最早整数孕周 |
| 组内差异控制 | 同时考虑平均达标概率、组内个体差异和样本量 |
| 结果稳定性 | 检查组数、切点和时点是否随折分或患者重采样发生明显变化 |
| 测量误差处理 | 检查Y浓度扰动是否推翻推荐政策 |
| 部署简化 | 将不稳定的小数切点转化为便于解释和执行的方案 |

目标不是机械增加组数，而是在综合相关因素后，寻找可靠性、检测时间、稳定性和可解释性之间的平衡。

### 3. 指标定义

#### 3.1 维持定义

总体预测达标概率、准确性风险、平均推荐孕周、题面分段时间风险、连续时间风险、不稳定风险、综合风险、Bootstrap安全率、重复折安全率和测量误差状态改变率沿用前述定义。

#### 3.2 新增定义

设某一BMI组在孕周`t`的平均预测达标概率为`p̄_g(t)`、组内标准差为`s_g(t)`、人数为`n_g`，定义单侧保守下界：

\[
LCB_g(t)=\bar p_g(t)-1.645\frac{s_g(t)}{\sqrt{n_g}}.
\]

新增指标如下：

| 指标 | 定义 | 作用 |
|---|---|---|
| 组内保守下界 | `LCB_g(t)` | 同时反映组内均值、个体差异和样本量 |
| 均值安全折数 | 外层测试折中最低平均达标概率达到安全线的折数 | 评价平均意义下的跨折可靠性 |
| 保守下限安全折数 | 外层测试折中最低LCB达到安全线的折数 | 评价更严格的跨折可靠性 |
| 切点Bootstrap区间 | 切点Bootstrap分布的2.5%和97.5%分位数 | 评价精确切点的抽样稳定性 |
| 组数选择稳定率 | 某组数在Bootstrap中被选择的次数除以总次数 | 评价分组结构是否反复出现 |

#### 3.3 变更定义

安全周由主要依据组内平均达标概率，调整为优先依据保守下界：

\[
t_g^*=\min\{t:LCB_g(t)\ge q\}.
\]

开发安全裕量取`q=0.95`。判优顺序调整为：先保证候选可行和保守可靠，再比较均值可靠性与平均推荐孕周；性能接近时优先采用组数更少、切点更稳定且更容易解释的结构。

### 4. 模型与算法组件及选取缘由

| 模型或算法 | 是什么 | 选取缘由 | 解决的问题 |
|---|---|---|---|
| 多因素XGBoost-AFT | 在删失时间模型中加入BMI、年龄、身高、体重、IVF、孕次和产次 | 能处理删失并表示多因素非线性关系 | 生成综合相关因素后的达标概率 |
| 有序动态规划 | 按BMI排序，在连续BMI区间中组合可行分段 | 固定约束下可比较完整切点组合，避免局部贪心 | 确定连续BMI分组及切点 |
| 保守下界安全周搜索 | 根据LCB确定组内最早安全孕周 | 防止平均值掩盖组内高风险个体 | 确定稳定检测周期 |
| 嵌套政策选择 | 每个外层训练折内部重新选择分组和时点 | 防止外层测试结果参与选参 | 评价整套优化流程的泛化能力 |
| 患者Bootstrap | 以孕妇为单位重采样并重新执行政策审计 | 检查切点和政策是否由少量患者决定 | 评价抽样稳定性 |
| 测量误差模拟 | 按重复检测估计的误差扰动Y浓度 | 检查4%附近状态变化 | 评价最终政策对测量误差的敏感程度 |

### 5. 整体路线/算法结构

```text
患者级删失数据
        ↓ 加入年龄、身高、体重、BMI、IVF、孕次和产次
多因素XGBoost-AFT
        ↓ 生成不同孕周前达到4%的OOF概率
BMI稳定排序
        ↓ 有序动态规划搜索连续BMI分组
保守下界安全周搜索
        ↓ 外层训练折内部选择分组、切点和时点
嵌套外层审计
        ↓ Bootstrap切点与政策稳定性分析
测量误差模拟
        ↓ 简化切点并形成可执行政策
```

### 6. 训练方案

#### 6.1 多因素达标概率训练

输入特征为：

\[
x_i=(BMI,Age,Height,Weight,IVF,Gravidity,Parity).
\]

输出为：

\[
F_i(t)=P(T_i\le t\mid x_i).
\]

删失似然、患者级外4折、内3折和OOF概率生成方式沿用前述方案。输出仍为267行患者级概率曲线，后续优化读取冻结概率，不重新拟合AFT模型。

#### 6.2 BMI分组结构训练

将孕妇按BMI稳定排序，只允许在相邻不同BMI值之间设置切点。对每个候选BMI区间，计算不同孕周下的组内均值和LCB，寻找满足`LCB≥0.95`的最早孕周；不存在安全孕周的区间记为不可行。

有序动态规划组合多个可行区间，并在给定实验约束下最小化：

\[
\sum_g n_gt_g,
\]

即最小化患者加权平均推荐孕周。每个开发折搜索`1..floor(n开发/30)`个组；约200名开发患者时实际覆盖1—6组。

#### 6.3 推荐时点与部署政策训练

在每个外层训练折内完成分组、切点和时点选择；以开发平均孕周为效率指标，在相差不超过0.25周的近优方案中优先选择更简单的结构。冻结后应用到该折测试孕妇，外层测试结果不参与当前折的选参。

全样本开发阶段曾得到切点34.357。完成全部可行组数搜索、固定候选Bootstrap和外层固定回放后，为提高部署可解释性并避免把开发样本的小数切点误作医学阈值，最终冻结整数切点35；34.357仅保留为前期开发证据，不作为最终部署切点。

## 六、第四问解答

### 1. 数据特征分析

女胎数据包含605条检测记录、147名孕妇和31个原始字段，平均每名孕妇约4.12条记录，最多9条。标签来自附件AB列“染色体的非整倍体”，将组合字符串拆为三个非互斥二元标签。

| 标签 | 阳性记录数 | 阳性孕妇数 | 数据障碍 |
|---|---:|---:|---|
| T13 | 23 | 18 | 阳性较少，指标波动较大 |
| T18 | 46 | 30 | 三类中样本相对最多，但仍明显不平衡 |
| T21 | 13 | 12 | 极少样本，最容易出现不稳定和过拟合 |
| 任一异常 | 67 | 44 | 适合总体风险排序，但不能替代染色体特异判定 |
| 未列出异常 | 538 | — | 占大多数，普通准确率会产生误导 |

附件存在T13T18、T13T21和T18T21等组合标签，因此不能建成互斥多分类。AE列“胎儿是否健康”605条均为“是”，没有可用于监督学习的真实临床结局；当前只能复现AB列筛查标签，不能声称诊断真实胎儿疾病。

同一孕妇存在重复检测，若随机拆分记录会导致同一孕妇同时进入训练集和测试集。BMI缺失1条，两列无名列全部为空；标签严重不平衡，筛查任务需要优先控制漏检，同时承担较多假阳性和复测负担。

### 2. 问题分析

| 大类问题 | 具体任务 |
|---|---|
| 多标签异常判定 | 同时输出T13、T18和T21概率及非互斥标签 |
| 类别不平衡 | 防止模型只预测大量阴性记录而获得虚高准确率 |
| 重复检测 | 保证同一孕妇全部记录始终位于同一数据折，并限制多次检测孕妇的总权重 |
| 概率与阈值 | 将连续风险概率转化为染色体特异阳性/阴性判定 |
| 概率校准 | 使模型分数尽可能具有概率解释 |
| 不确定记录 | 对阈值附近结果设置复测区，而不是强制二分类 |
| 测序质量 | 识别读段、比对比例、GC等质量极端记录 |
| 方法对照 | 与固定Z值规则和训练型Z值规则公平比较 |
| 结论边界 | 明确输出属于附件筛查标签复现和研究性分流 |

### 3. 指标定义

#### 3.1 维持定义

患者级外层测试、内层OOF选参、患者Bootstrap、输入哈希固定和测试折不参与参数选择等验证定义沿用前述原则。模型稳定性继续通过不同外层折和患者重采样评价，不按检测记录独立抽样。

#### 3.2 新增定义

设`TP、TN、FP、FN`分别为真阳性、真阴性、假阳性和假阴性。

| 指标 | 定义 | 作用 |
|---|---|---|
| 灵敏度 | `TP/(TP+FN)` | 衡量阳性标签被检出的比例，筛查任务优先关注 |
| 特异度 | `TN/(TN+FP)` | 衡量阴性记录被正确排除的比例 |
| 阳性预测值PPV | `TP/(TP+FP)` | 衡量模型阳性中附件标签阳性的比例 |
| 阴性预测值NPV | `TN/(TN+FN)` | 衡量模型阴性中附件标签阴性的比例 |
| F1 | 精确率和召回率的调和平均 | 平衡漏检和误报 |
| F2 | 对召回率赋予更高权重的F分数 | 符合筛查阶段漏检代价较高的取向 |
| ROC-AUC | 灵敏度—假阳性率曲线下面积 | 衡量概率排序能力，但不单独判优 |
| PR-AUC | 精确率—召回率曲线下面积 | 类别不平衡下的主排序指标 |
| Brier分数 | `mean[(p-y)^2]` | 衡量概率误差，越小越好 |
| 复测率 | 被标记为阈值附近或质量异常的记录比例 | 衡量不确定性处理带来的执行成本 |
| 患者Bootstrap区间 | 以孕妇为单位有放回抽样得到的指标分位数区间 | 衡量小样本和稀有阳性造成的不确定性 |

#### 3.3 变更定义

任务输出由“首次达标时间和推荐孕周”变更为“染色体异常概率、多标签判定和复测状态”。主判优指标变更为宏平均PR-AUC及稀有标签灵敏度；阈值选择优先保证灵敏度不低于85%，再最大化特异度，并以F2处理并列。普通准确率不作为主指标。

任一异常概率采用三个染色体概率并集：

\[
p_i(any)=1-\prod_{c\in\{13,18,21\}}(1-p_{ic}).
\]

该概率用于总体风险排序；染色体特异性标签仍由三个独立阈值决定。

### 4. 模型与算法组件及选取缘由

| 模型或算法 | 是什么 | 选取缘由 | 解决的问题 |
|---|---|---|---|
| 三个代价敏感XGBoost分类器 | 分别预测T13、T18和T21概率 | 能表示Z值、GC、读段质量和孕妇特征的非线性交互 | 多标签概率筛查 |
| 患者等权 | 同一孕妇每条记录权重与其记录数倒数成正比 | 防止多次检测孕妇支配损失 | 重复检测计权偏差 |
| 正类权重 | 每个训练折中以阴性数/阳性数提高正类损失权重 | 缓解阳性稀少导致的全阴性倾向 | 类别不平衡 |
| Platt校准 | 用内层OOF分数拟合单变量sigmoid概率映射 | 改善模型分数的概率解释 | 概率校准 |
| 灵敏度优先阈值搜索 | 在内层OOF概率的全部候选阈值中按固定规则选择 | 阈值不读取外层测试标签 | 概率到判定的转换 |
| 阈值不确定带 | 根据预测概率到阈值的距离确定复测区 | 避免对边界记录强制二分 | 不确定记录处理 |
| 训练折质量分位数 | 根据读段、比对、重复、过滤和GC分布标记质量极端 | 不使用测试折统计量设定质量线 | 低质量检测识别 |
| Z值规则对照 | 固定`|Z|≥3`及训练折内搜索的Z阈值 | 提供简单透明的传统基准 | 判断复杂模型是否提供额外筛查能力 |

### 5. 整体路线/算法结构

```text
605条女胎检测记录
        ↓ 标签拆分、孕周转换、缺失和泄漏字段处理
T13/T18/T21三个非互斥标签
        ↓ 患者级外4折、内3折
三个代价敏感XGBoost分类器
        ↓ 内层OOF参数选择与Platt概率校准
染色体特异概率
        ↓ 灵敏度优先阈值搜索
T13/T18/T21多标签判定
        ↓ 概率并集形成任一异常风险
阈值不确定带＋测序质量规则
        ↓
筛查阳性／筛查阴性／阈值附近复测／质量异常重抽
        ↓
Z值规则对照＋患者Bootstrap稳定性评价
```

### 6. 训练方案

#### 6.1 多标签概率模型训练

对每个染色体`c∈{13,18,21}`分别训练分类器：

\[
p_{ic}=P(y_{ic}=1\mid x_i).
\]

输入包括目标染色体及X染色体Z值、X染色体浓度、读段数量与比例、GC含量、年龄、身高、体重、BMI、孕周、IVF、孕次、产次和抽血次数；同时构造绝对Z值、最大绝对Z值、Z值间差异、唯一比对读段占比、GC偏离量及BMI缺失指示。

每个训练折内计算患者等权`v_i`和正类权重`α_c`，优化带权二元对数损失：

\[
L_c=-\sum_i v_i[\alpha_cy_{ic}\log p_{ic}+(1-y_{ic})\log(1-p_{ic})]+\Omega(f_c).
\]

内层候选配置比较树深、学习率、采样率、正则化和迭代轮数，主评分为PR-AUC，辅助参考F2和概率误差。

#### 6.2 概率校准与阈值训练

用完整内层OOF原始概率拟合Platt校准器，再作用于外层测试原始概率。内层OOF阳性少于8条、阴性少于20条或校准器数值失败时，回退到原始XGBoost概率。

对每个染色体枚举相邻唯一概率的中点及两个端点作为候选阈值。阳性样本充足时，先保留灵敏度不低于85%的阈值，再选择特异度最高者；并列时依次选择F2更高和阈值更高者。样本不足或无可行阈值时，改为优先最大化F2。

#### 6.3 复测与最终分流规则训练

定义阈值距离`d_ic=|p_ic-t_c|`，不确定带宽取训练OOF距离的15%经验分位数且不超过0.15。若任一染色体位于不确定带，则建议复测。

测序质量规则只使用训练折分位数：六项质量指标中至少两项越界，或总/唯一读段数低于训练折0.5%分位点时，标记质量异常并建议重抽复检。最终分流优先级为质量异常、阈值附近、筛查阳性、筛查阴性。

### 7. 验证方案

外层4折按孕妇分组，每折测试36—37名孕妇、151—152条记录；患者重叠数为0。内层3折完成特征处理、参数选择、校准、阈值和复测带宽确定。分折使用患者级多标签平衡搜索，使每个外层测试折均包含T13、T18和T21阳性孕妇。

每个染色体分别与固定`|Z|≥3`规则和训练型Z阈值比较。患者级Bootstrap重复2000次，报告灵敏度、特异度、PR-AUC、ROC-AUC、F2和Brier分数的95%区间。若稀有标签长期零召回、性能低于Z值基准、Bootstrap下限接近随机或复测负担失控，则不得宣称主模型有效。

2. AB列是当前需要复现的附件筛查标签；AE列缺乏真实阴性/阳性变化，不能验证真实疾病诊断能力。
3. 患者级三分流提高了直接阳性的特异度和PPV，但需要48.3%的复测率，并仍存在4名附件异常标签未覆盖者。
4. T21只有13条阳性记录，Bootstrap区间宽，当前证据不足以宣称稳定预测。
5. 患者级三分流采用复测率不超过55%的开发约束，外层汇总复测率为48.3%；该负担必须与覆盖灵敏度0.909同时报告。
6. 当前只有内部嵌套患者级验证，尚无独立医院、真实核型或出生结局外部验证。
7. 最终方法仅用于数学建模和研究性筛查分流，不构成临床诊断或处置意见。
