# 问题 3 尝试解答：相关性、替代性与互补性下的种植策略

> 本文是交给编程手的建模草稿。真实数值必须由代码运行产生，不能直接把文中的模拟参数当作附件观测值或比赛结论。

## 1. 题意与数据边界

问题 3 要在问题 2 的基础上考虑：

1. 作物之间的替代性与互补性；
2. 预期销量、销售价格和种植成本之间的相关性；
3. 用模拟数据求解 2024—2030 年种植策略；
4. 与问题 2 结果比较。

附件只有 2023 年单年截面，不能可靠估计 41 种作物的时间相关矩阵、交叉价格弹性或轮作增产率。因此主模型将这些量设计为公开的模拟参数，并做弱、中、强三档敏感性分析。

## 2. 方案优先级

| 优先级 | 方案 | 定位 |
|---:|---|---|
| 1 | 因子 t-Copula 相关情景 + 交叉价格弹性 + 豆类前茬互补 + 均值—下尾 CVaR 随机 MILP | 主模型，必须实现 |
| 2 | Wasserstein 或矩约束分布鲁棒 MILP | 只有主模型对模拟参数明显失稳时回退 |
| 3 | 系统动力学/多智能体 + 启发式 | 数据不足且无最优性界，不实现 |

问题 3 只实施优先级 1；后两项不是并行模型。

## 3. 集合、参数与变量

沿用问题 2：

- `j in J`：54 个地块或大棚；
- `i,h in I`：41 种作物，`h` 专用于表示影响作物；
- `t in T={2024,...,2030}`；
- `s`：种植季次；
- `omega in Omega`：代表情景；
- `A_j`：地块面积，亩；
- `x_jits`：种植面积，亩；
- `y_jits`：作物启用变量；
- `r_jt`：水浇地模式变量；
- `u_its^omega`：正常价销量，斤；
- `Pi_omega`：七年利润，元。

新增：

- `L`：因子载荷矩阵；
- `R_lat`：t-Copula 潜在线性相关矩阵；
- `tau*`：目标 Kendall 秩相关；
- `E^(s)=(e_ih^(s))`：季次交叉价格弹性矩阵；
- `b_jt`：上一年度是否启用过豆类；
- `w_jits=x_jits*b_jt`：互补面积线性化变量；
- `gamma_i`：豆类前茬增产率。

所有种植决策不带情景下标，保证输出是一套事先制定的共同策略。

## 4. 相关情景生成

### 4.1 非退化边际

先按问题 2 生成 LHS 边际，再对问题 3 中需要相关的确定趋势作以下模拟扩展：

| 参数 | 问题 3 边际 |
|---|---|
| 小麦、玉米销量 | 年增长率 `[5%,10%]`，逐年递推 |
| 其他作物销量 | 相对 2023 年 `[-5%,5%]`，不累积漂移 |
| 亩产量 | 相对 2023 年 `[-10%,10%]` |
| 成本 | 年增长率 `[4%,6%]`，逐年递推 |
| 粮食价格 | 当年趋势基线附近 `[-1%,1%]`，不累积 |
| 蔬菜价格 | 年增长率 `[4%,6%]`，逐年递推 |
| 普通食用菌价格 | 年下降率 `[1%,5%]`，逐年递推 |
| 羊肚菌价格 | 固定年下降 5%，从价格 Copula 维度剔除 |

粮价 `±1%` 是对“基本稳定”的模拟化解释，必须在报告中标明，不是题面给定区间。

### 4.2 因子 t-Copula

每种作物唯一映射到粮食、蔬菜、食用菌之一。公共因子包括：宏观成本、全局气候，以及各类别需求和类别气候因子。

基准载荷：

| 随机维度 | 宏观 | 全局有利气候 | 本类别需求 | 本类别气候 |
|---|---:|---:|---:|---:|
| 成本增长率 | +0.60 | 0 | 0 | 0 |
| 基础销量变化率 | -0.10 | 0 | +0.50 | 0 |
| 价格变化率 | +0.30 | -0.30 | +0.35 | 0 |
| 亩产变化率 | 0 | +0.60 | 0 | +0.25 |

因子七年路径采用稳态初始化 `g_{k,2024}\sim N(0,1)`；随后对 `t=2025,...,2030` 递推：

\[
g_{k,t}=\rho_k g_{k,t-1}
+\sqrt{1-\rho_k^2}\nu_{k,t},
\quad \nu_{k,t}\sim N(0,1).
\]

每个情景只抽取一个 `S_omega~chi-square(nu)`，由该情景内全部作物、参数和七个年份共享：

\[
z_{a,t}^{\omega}=
\frac{\sum_kL_{ak}g_{k,t}^{\omega}
+\sqrt{1-\sum_kL_{ak}^2}\epsilon_{a,t}^{\omega}}
{\sqrt{S_{\omega}/\nu}}.
\]

潜在线性相关矩阵必须半正定。t-Copula 目标 Kendall 相关为

\[
\tau_{ab}^{*}=\frac{2}{\pi}
\arcsin((R_{lat})_{ab}).
\]

不能把 `R_lat` 直接称为 Spearman 矩阵。相关 t 分数只提供秩次，用它重排每一维 LHS 样本，从而保留边际分层和相关结构。

基准：`nu=5, kappa_R=1, rho_k=0.5`。弱、中、强档：

- `kappa_R in {0.5,1.0,1.25}`，统一缩放非零载荷；
- `rho_k in {0.25,0.50,0.75}`；
- `nu in {5,8,Gaussian}`。

审计对集合确定为所有 `|tau*|>=0.10` 的非对角无序变量对，并强制并入同一随机维度相邻年份的全部变量对，不得手工挑选。原始样本在该集合上的 Kendall 最大绝对误差不得超过 0.05；缩减样本以情景权重计算加权 Kendall，要求方向一致且最大绝对误差不超过 0.15，否则增加代表情景数。

## 5. 替代性：交叉价格弹性

令 `D_base,omega_its` 是完成相关抽样但尚未施加弹性的销量，`bar_p_its` 是问题 2 当年确定趋势价格。最终销量为

\[
D_{its}^{\omega}=D_{its}^{base,\omega}
\exp\left[
\sum_{h\in I_s}e_{ih}^{(s)}
\ln\left(\frac{p_{hts}^{\omega}}{\bar p_{hts}}\right)
\right].
\]

- `e_ii<0`：自身价格上升，销量下降；
- `e_ih>0`：`i,h` 为替代品；
- `e_ih<0`：市场消费互补；
- 无依据的跨组边为 0；
- 只在同一销售季次设置弹性边。

稳定条件：

\[
\sum_{h\ne i}|e_{ih}^{(s)}|
\le |e_{ii}^{(s)}|.
\]

基准模拟参数：

| 类别 | 自身弹性 | 每行同类替代边总和 |
|---|---:|---:|
| 粮食 | -0.25 | +0.15 |
| 蔬菜 | -0.50 | +0.20 |
| 食用菌 | -0.60 | +0.25 |

同类替代总和在有效邻边间均分，并整体乘 `kappa_E in {0.5,1.0,1.5}`。这些是模拟参数，不是附件估计值。

## 6. 互补性：豆类前茬增益

题面明确说明豆类根瘤菌有利于其他作物生长。令 `b_jt` 表示地块 `j` 上一年是否种过豆类，增加

\[
0\le w_{jits}\le x_{jits},
\]

\[
w_{jits}\le A_jb_{jt},
\qquad
w_{jits}\ge x_{jits}-A_j(1-b_{jt}).
\]

则 `w=x*b`。情景产量为

\[
Q_{its}^{\omega}
=\sum_jq_{jits}^{\omega}
\left(x_{jits}+\gamma_iw_{jits}\right).
\]

非豆类 `gamma_i in {0,0.03,0.06}`，豆类自身为 0。二元触发忽略豆类前茬覆盖比例，是强假设；若 0% 和 3% 即导致方案大幅翻转，应回退到按覆盖比例分段线性化。

## 7. 联合随机 MILP

销售约束：

\[
0\le u_{its}^{\omega}\le Q_{its}^{\omega},
\qquad
u_{its}^{\omega}\le D_{its}^{\omega}.
\]

利润：

\[
\Pi_{\omega}
=\sum_{t,i,s}p_{its}^{\omega}u_{its}^{\omega}
-\sum_{j,i,t,s}c_{jits}^{\omega}x_{jits}.
\]

下尾利润 CVaR：

\[
LCVaR_{\beta}
=\zeta-\frac{1}{1-\beta}
\sum_{\omega}\pi_{\omega}\xi_{\omega},
\quad
\xi_{\omega}\ge\zeta-\Pi_{\omega},
\quad \xi_{\omega}\ge0.
\]

目标：

\[
\max Z_{\lambda}^{(3)}
=(1-\lambda)E[\Pi]
+\lambda LCVaR_{\beta}(\Pi).
\]

所有适种、面积、水浇地模式、重茬、2023 边界、滚动三年豆类和最小种植面积约束继承问题 2。每个 `lambda` 继续执行：最大风险目标、最大期望利润、最小激活次数三级字典序求解。

## 8. 情景缩减

缩减特征必须包含：

1. 标准化参数变化率；
2. 公共因子得分；
3. Q2 固定基线下代理利润；
4. 低利润层标识。

采用分层 PAM k-medoids 和 L1 距离。最低利润 10% 层至少保留 `ceil(0.1K)` 个代表情景。缩减后除权重和尾部保护外，还要检查主要 Kendall 相关方向和误差。

## 9. 与问题 2 的比较

必须使用四组消融：

1. Q2 独立参数基线；
2. 仅加入相关性；
3. 仅加入替代与互补；
4. 完整 Q3。

Q2 组读取冻结的可行候选方案并只复算，不重新优化或重跑 `lambda` 网格；其余三组统一使用 `beta`、`lambda` 网格、情景规模、求解时限、gap 门槛和唯一方案选择规则。所有固定方案在同一批 Q3 样本外情景上复算，并采用共同随机数。

指标：期望利润、标准差、10%分位数、最差10%平均利润、最低利润、亏损概率、面积 L1 距离、激活 Jaccard 相似度和集中度。对 Q3-Q2 成对利润差做 bootstrap 区间。

当前 Q2 方案 `selected_certified=False`、风险前沿不完整，只能标为“Q2 可行候选基线”，不能写成已证明最优。

## 10. 结果解释规则

只有满足以下条件才能推荐 Q3 策略：

- 农业硬约束全部可行；
- 相关生成和边际范围审计通过；
- Q3 在共同相关情景中的下尾利润优于 Q2；
- 相对 Q2 的平均利润损失不超过预先设定的 2%，并同时报告 1%、3%、5% 门槛敏感性；
- 弱、中、强档下主要结构相对稳定；
- 求解器状态、bound 和 MIP gap 被完整披露。

若相关、弹性或轮作增益轻微变化就导致主要种植结构翻转，不给单一无条件结论，应报告条件性策略并转入分布鲁棒回退评估。
