# 问题3代码审计与修正指导

## 1. 审计结论

原产物存在会改变数学模型含义的错误，不能直接用于正式实验。本轮已修正 MILP、弹性、样本外评估和实际随机边际的独立特异项，并将原始/缩减 Kendall 改为真实计算的启动前硬门禁。当前允许启动程序执行门禁；只有门禁通过后才会进入基准 MILP 实验。

## 2. 已发现并修正的 P0/P1 问题

1. **豆科前茬 OR 逻辑反号**：原式实际约束为 `b<=y`，已改为 `y-b<=0`，与 `b<=sum(y)` 共同精确表示 OR。
2. **McCormick 下包络反号**：已改为 `-w+x+A*b<=A`，保证二进制 `b` 下 `w=x*b`。
3. **随机年路径伪递推**：已将需求、成本、蔬菜/食用菌价格改为每年独立 LHS 增量后逐年连乘，不再把同一年增长率直接幂运算。
4. **t-Copula 维度错配**：原代码用同一秩分数列重排全部参数与年份，且分类别独立抽卡方尺度。已改为联合因子映射，每个类别的 4×7 列各自对齐，所有类别共享情景卡方尺度及宏观/全局气候因子。
5. **价格弹性维度错误且静默降级**：已按季次构造 `(N,n_crop)` 的需求、情景价格和趋势价格矩阵；异常不再被吞掉。
6. **趋势价格基线错误**：已使蔬菜、食用菌、羊肚菌分别使用当年确定趋势，避免将长期趋势重复计入弹性冲击。
7. **情景缩减 K 超额与内存爆炸**：尾部代表改为“替换”而非“追加”；距离计算改为 `cdist`，不再构造 `N×N×F` 张量；因子得分纳入缩减特征。
8. **前沿资格字段不一致**：`status/solver_status` 已兼容，前沿完整性改为对所有 lambda 显式检查；膝点并列选更大 lambda。
9. **样本外评估被二次缩减**：已改为直接在全部独立 OOS 情景上配对复算 Q2/Q3。
10. **CVaR 复算调用参数错序**：已统一调用 Q3 独立利润复算。
11. **配置未生效**：主程序现在读取 lambda、分布、相关、弹性和互补参数，不再默认关闭 Q3 机制。
12. **不可用检查点伪恢复**：旧 JSON 不含方案向量，已禁止将它当作可恢复解，避免恢复后无法复算或导出。
13. **P1 伪通过**：去掉销量硬编码 PASS、OOXML 失败跳过和数值宽容差，改为真实约束复算。
14. **Windows Python 选错**：一键脚本优先使用已验证的 `E:\anaconda\python.exe`，启动前检查必需包，并用 `-u` 保证进度及时输出。

## 4. 启动方式与判定

在 `q3_test` 目录双击 `一键运行问题3.bat`，或在 PowerShell 运行：

```powershell
& 'E:\anaconda\python.exe' -u scripts\run_q3.py --config configs\q3_default.yaml --figures --reports
```

退出码 `0` 才表示全部当前硬门槛通过；`2` 表示有可行方案但前沿/认证未完成；`3` 表示未获得可用方案；`1` 表示输入、依赖、计算或导出异常。
